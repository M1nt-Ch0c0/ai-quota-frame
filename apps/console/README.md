# PhotoPainter macOS 控制台

SwiftUI 界面通过本机 Unix socket 使用已有 Go 后台。后台串行执行蓝牙操作与推图，界面不打开 USB 串口，不读取普通服务日志。

## 设备与应用

- “切换到此应用”使用该应用的 active 版本。ABI 1 和 ABI 2 都可手动选择；`button_eligible` 仅代表设备功能键的候选资格。
- A/B 各显示版本和用途：已激活、待激活、可回退、备用或未安装。`null` 槽显示为空，版本 0 仍是有效版本。
- 待激活槽调用 activate；previous 槽调用 rollback。回退非运行应用后，先确认目录，再单独切入该应用。
- 无 pending/previous 标记的备用槽，宿主目前没有直接选择接口。选择同应用、同版本的 `.pkg` 后，后台核对确认时的 SHA-256，重新暂存到非 active 槽，确认 pending 后再激活。此流程允许恢复同版本，保留原 active。
- 新应用包的普通安装仍要求更高版本，并单独激活；不要把宿主 `.bin` 或原始 `.elf` 当应用包。
- 旧 ABI 1 切入后先是已载入，需 PNG 输入才能确认。可用“结束试运行”返回原选择；当前相框 BLE 收图需要 ABI 2.1 应用。

状态超过两分钟只影响新鲜度提示，不禁用操作。每次管理操作在取得共享队列后重新读取鉴权状态，核对所选槽和版本。传输结果不确定时禁止修改；缺失命令回复只查询结果，不自动重复命令。

## 构建与验证

```sh
make check
sh apps/console/build.sh
```

产物为 `dist/PhotoPainter Console.app` 和 `dist/ai-quota-frame`。两者需要配套更新；原生启动器、私有配置和暂停设置保持在既有运行目录。

`console_slots_test.go` 覆盖手动切入 ABI 1、过期版本拒绝、A/B 激活与回退、非运行应用回退后切入、同版本恢复、包校验与暂存确认、空槽与版本 0、丢回复不重放及结束试运行。硬件验收需另外读取设备状态，不能用这些模拟结果代替。
