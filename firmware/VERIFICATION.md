## 尚未证明的真实行为

1. 在 SD 放两组真实 Wi-Fi，重启优先连接第一组；使其不可用后重启连接第二组；列表未丢失。
2. 全部连接失败时进入恢复 AP，新增或更新后可以连接，其他记录保留。
3. 真机无鉴权/错误鉴权的 push 和旧写接口返回 401，不触发刷屏。
4. 正确码 POST 标准六色 PNG 得到 200，SD 当前图逐字节读回匹配，面板肉眼显示正确。
5. 断电重启和移除 SD 后，鉴权保持；超大、损坏、中断上传不破坏上一张图。

执行方法见 [README](README.md) 的真机验收部分。以上项目未完成前，不将整个开发目标标记完成。

## 已知限制

- 推图使用受信局域网 HTTP Bearer 鉴权，并非加密传输；不应暴露公网。
- 开启推图码会默认关闭深睡和自动轮播，以维持入站可达性；仍建议 USB 供电。
- SD 密码明文，推图码也可由具有物理存储访问权限的人读取；这不是安全启动或加密存储方案。
- npm 安装仍报告上游锁定依赖的审计告警：webapp 8 项、process-cli 4 项。本轮未做依赖升级或安全发布认证，不把测试通过表述为生产安全认证。
- 尚未修改或刷写用户设备；GitHub 交付使用独立 feature 分支和开发预发布包，真机验证由用户自行执行，不代表已验收完成。
